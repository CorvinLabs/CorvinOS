ARCHITECTURAL DECISIONS
================================================================================

1. Real Setuptools (not fake):
   - Uses subprocess.run([sys.executable, "-m", "build", ...])
   - Respects wheel-build standard (PEP 517)
   - No wheel synthesis in Python (prevents subtle bugs)

2. Audit-First Design (ADR-0232):
   - build_started emitted BEFORE any action
   - build_completed/build_failed emitted AFTER wheel validation
   - Never loses audit trail even if build partially fails
   - Hash-chained: tamper-evident append-only log

3. Tenant Isolation (ADR-0114):
   - BuildConfig.tenant_id validated on init (fail-closed)
   - All audit events include tenant_id
   - Version manager is tenant+skill scoped
   - Cross-tenant leakage impossible (enum-based validation)

4. Immutable Manifest (ADR-0264):
   - PluginManifest frozen=True (dataclass)
   - contract_hash computed once at init
   - Frontmatter generated from immutable snapshot
   - Prevents post-creation tampering

5. Semantic Versioning:
   - BuildConfig supports version_strategy="semver"
   - TenantSkillVersionManager owns version history
   - Rollback to ROLLBACK_READY versions supported
   - Version incompatibilities caught early

6. Fail-Closed Gates:
   - Manifest validation is mandatory (no skip flag)
   - Wheel validation is mandatory (skip_wheel_validation=False hardcoded)
   - Tenant isolation is mandatory (validate_tenant_id() called)
   - Audit chain failures are fatal (RuntimeError on write failure)

FAILURE MODES & RECOVERY
================================================================================

If audit chain unreachable:
  → build() returns BuildResult with success=False
  → Error message: "Failed to write audit event to {path}"
  → User can retry after fixing tenant directory permissions

If setuptools not installed:
  → build() returns BuildResult with success=False
  → Error message: "build module not found. Install with: pip install build"
  → User installs module and retries

If manifest validation fails:
  → build_started event emitted (if audit enabled)
  → build() returns BuildResult with success=False
  → validation_issues list populated in result.errors

If wheel validation fails:
  → wheel_path still available for inspection
  → build() returns BuildResult with success=False
  → wheel_issues detail what failed
