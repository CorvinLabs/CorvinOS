DETAILED FINDINGS
================================================================================

FIX M1: Registry Load Fail-Closed (HIGH severity)
─────────────────────────────────────────────────
BEFORE: load_registry() silently treated unparseable files as empty, then
        save_registry() would overwrite them → DATA LOSS

AFTER:  Fail-closed validation:
        - Unreadable YAML → raises ValueError
        - Wrong shape (non-mapping) → raises ValueError
        - List-shaped "plugins" field → raises ValueError
        - Only missing files are treated as empty

VERIFICATION: Code path confirmed, ValueError raising on all error cases.

FIX M2: Path Traversal in Uninstall (CRITICAL severity)
────────────────────────────────────────────────────────
BEFORE: 'corvin plugin uninstall ../../x' could delete /home/shumway/x
        One path validation failure = full compromise

AFTER:  _safe_installed_dest() enforces TWO independent guards:
        1. validate_plugin_id() — allowlist charset rejects .. / \
        2. Resolved containment — even slipped id cannot escape tenant
        Defense in depth: if one guard fails, the other stops it

VERIFICATION: Both guards confirmed in code, applied to register/unregister.

FIX 2.1: Tarball Path Traversal (CRITICAL severity)
─────────────────────────────────────────────────────
BEFORE: tar.extractall(path=temp_dir) without filter
        Malicious tarball with ../../../etc/passwd → escapes temp_dir

AFTER:  tar.extractall(path=temp_dir, filter="data")
        PEP 706 standard filter rejects:
        - Absolute paths (/etc/passwd)
        - Traversal paths (../../../etc/passwd)
        - Symlinks (can point outside)
        - Device files

VERIFICATION: filter="data" confirmed in code. Python 3.11+ standard feature.

FIX 2.2: rmtree of /tmp (CRITICAL severity)
──────────────────────────────────────────────
BEFORE: Cleanup logic: shutil.rmtree(plugin_dir.parent)
        When plugin.yaml at tarball root:
        - plugin_dir = /tmp/xyz/
        - plugin_dir.parent = /tmp → WIPES SYSTEM TEMP

AFTER:  Function returns all three paths explicitly:
        - manifest_data
        - plugin_dir (may == temp_dir if at root)
        - temp_dir (explicit owner)
        Caller uses ONLY temp_dir for cleanup, never .parent

VERIFICATION: Function signature enforces ownership, cleanup never guesses path.
