CRITICAL VULNERABILITIES (Fix Within 24 Hours)
================================================================================

[CRITICAL #1] Consent Gate Bypass — Permits All Users
─────────────────────────────────────────────────────
  Location: core/compliance/consent.py:68-102
  Issue:    @consent_required decorator is a stub implementation
            - Comment says "For now, permit all authenticated users (temporary)"
            - Real consent check is commented out (TODO)
            - Users can perform state-changing operations without explicit consent
  Impact:   GDPR Art. 6 violation - affirmative consent requirement bypassed
  Exploit:  Any authenticated user can bypass consent requirements
  Fix:      Replace stub with actual consent_store.check_consent() call

[CRITICAL #2] Unauthenticated Audit Writing — Cross-Tenant Leakage
──────────────────────────────────────────────────────────────────
  Location: core/console/corvin_console/routes/intents.py:57,138
  Issue:    POST /v1/console/intents/classify and GET /recent
            - NO require_session authentication
            - tenant_id taken directly from user input
            - Any user can write/read audit events for ANY tenant
  Impact:   Attacker can pollute other tenants' audit chains
            Attacker can exfiltrate other tenants' audit events
            Violates ADR-0007 (tenant isolation) + GDPR Art. 32
  Exploit:  curl -X POST http://localhost:8765/v1/console/intents/classify \
              -d '{"text":"...", "tenant_id":"victim-tenant"}'
  Fix:      Add Depends(require_session) + validate tenant_id matches user

[CRITICAL #3] A2A Peer Validation Bypass
─────────────────────────────────────────
  Location: core/console/corvin_console/api/multi_instance_sync.py:317-322
  Issue:    _is_valid_peer_id() only checks if string is non-empty
            - Comment: "TODO: Query actual A2A registry"
            - "CRITICAL: This is a temporary workaround pending A2A registry"
            - Route accepts any peer_id and returns success
  Impact:   Configuration (with secrets/credentials) sent to attacker-controlled peers
            Man-in-the-middle attacks enabled on config sync
  Exploit:  Attacker specifies own server as peer_id, receives all config
  Fix:      Replace stub with actual call to forge.a2a.list_peers()
            Fail-closed on unknown peers

[CRITICAL #4] Licensing Endpoint Unauthenticated
────────────────────────────────────────────────
  Location: core/console/corvin_console/routes/licensing_verify.py:60-61
  Issue:    POST /v1/licensing/verify has NO authentication
            - No Depends(require_session)
            - Accepts arbitrary tenant_id parameter
            - Returns license tier, quota, upgrade URLs
  Impact:   Information disclosure: attacker learns other tenants' license tiers
            Attacker can determine quota exhaustion for DoS planning
  Exploit:  curl -X POST http://localhost:8765/v1/licensing/verify \
              -d '{"capability":"compute.run"}' \
              -G --data-urlencode 'tenant_id=victim-tenant'
  Fix:      Add Depends(require_session) authentication
