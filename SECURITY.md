# Security Policy

## Reporting Security Issues

CorvinOS takes security issues seriously. If you discover a security vulnerability, please email security@corvinlabs.com instead of using the public issue tracker.

Please include:
- Description of the vulnerability
- Steps to reproduce
- Impact assessment
- Any suggested fixes

## Security Updates

Security updates will be released as soon as possible following the discovery and verification of vulnerabilities. Users should regularly update their installations.

## Compliance & Standards

CorvinOS is designed to comply with:
- GDPR (General Data Protection Regulation)
- EU AI Act 2026
- Audit trail requirements (ADR-0232/0233)
- End-to-end encryption standards

For detailed security architecture, see `docs/claude-ref/layer-security.md`.
