# Tutorial: Install Skills from Marketplace (5 min)

## Goal
Install a community Skill and use it in your projects.

## Steps

1. **Browse Marketplace**
   - Console → Marketplace → Browse Skills

2. **Find Skill**
   - Search: "text-summarizer"
   - View details + reviews

3. **Install**
   - Click "Install"
   - Verify SHA256 checksum

4. **Use in Project**
   - Skill now available in Skill Forge
   - Create workflows using it

5. **Update**
   - New versions auto-notify
   - Click "Update" to upgrade

## Marketplace Types
- **Builtin** — Core CorvinOS Skills (maintained)
- **Vetted** — Community Skills (reviewed)
- **Community** — Self-published (use with caution)
