# CorvinOS v0.9: Real-Time Dashboard

**Release Cycle:** 4 weeks (2026-12-22)  
**Status:** Design Phase  
**Depends on:** v0.6 + v0.8

---

## Five Core Ideas

### 1. Live Subsystem Monitor

**Idea:** Real-time view of Brain's 13 subsystems health (HealthMonitor, ContextBridge, etc.).

**What operator sees:**
- Green/yellow/red status per subsystem
- Latency histogram (p50, p95, p99)
- Throughput (turns/sec)
- Error rate + recent errors

**Success metric:** Dashboard load <2s, update latency <500ms.

---

### 2. Decision Stream

**Idea:** Real-time WebSocket stream of every decision + metadata.

**Stream events:**
- `decision_made` (operator chose option A)
- `cost_incurred` (turn cost $0.045)
- `confidence_update` (model confidence 87%)
- `plugin_invoked` (plugin X suggested)
- `engine_switched` (switched to ACS)

**Success metric:** <500ms latency, 99.9% uptime.

---

### 3. Interrupt Protocol

**Idea:** Pause, resume, redirect turn mid-execution.

**Actions:**
- **Pause:** Stop current turn, save state
- **Resume:** Continue from pause point
- **Redirect:** Switch to different engine (native → ACS, etc.)

**Success metric:** 100% interrupt success, <100ms pause latency.

---

### 4. Cost Burn Visualization

**Idea:** See API costs in real-time: quota, hourly burn rate, projections.

**Visualization:**
```
┌──────────────────────────────────────┐
│ Cost Tracker                         │
├──────────────────────────────────────┤
│ Budget:      $100.00                 │
│ Spent:       $42.50 (42.5%)          │
│ Burn rate:   $12.50/hour             │
│ Projected:   $300 (exceeds budget!)  │
│ Days left:   0.7 days                │
│                                      │
│ [View breakdown by engine]           │
│ [Adjust budget]                      │
└──────────────────────────────────────┘
```

**Success metric:** <100ms to update cost displays.

---

### 5. Operator Annotation Loop

**Idea:** Operator can mark decisions as good/bad, capture feedback.

**How it works:**
- While viewing decision stream, click 👍 or 👎
- Optional free-form feedback (why was this good/bad?)
- Feedback stored + used for learning
- Can view all annotations in Learning tab

**Success metric:** >50% annotation adoption (operator rate).

- Dashboard events not exported (transient)
