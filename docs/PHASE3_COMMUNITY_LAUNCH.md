# Phase 3 Community Launch Procedure

**Trigger:** Phase 2 stable (48h green metrics)  
**Timeline:** Week 1 of Phase 3  
**Deliverable:** Community invites + first Skill submissions

---

## Launch Checklist (Day 1)

- [ ] Phase 2 metrics verified (P99 <120ms, error rate <0.15%, feedback >50/hr)
- [ ] Marketplace API tested (submit, discover, rate endpoints live)
- [ ] Authoring guide published (SKILL_AUTHORING_GUIDE.md live on docs)
- [ ] Slack #skills-authoring channel created
- [ ] GitHub discussions enabled (Skill feedback)
- [ ] First 5 beta testers invited (internal team)

## Week 1: Beta Testing (Internal)

1. Internal team submits 5 reference Skills
2. Test submission → vetting → approval workflow
3. Test marketplace discovery + ratings
4. Document any issues in runbook

## Week 2: Alpha Launch (25 Developers)

1. Invite 25 developers (from community, universities)
2. Host live Q&A: "Skill Authoring 101" (video walkthrough)
3. Monitor submissions (expect 3-5)
4. Update authoring guide based on feedback

## Week 3+: Beta Launch (Community)

1. Public announcement: "ACP Skills Marketplace LIVE"
2. Publish blog post: "How to Write Your First Skill"
3. Open submissions (anyone with GitHub account)
4. First wave: expect 20-50 submissions

## Success Metrics (Week 4)

- 10+ submissions received
- 5+ approved (passed auto-check + human review)
- 2+ Bronze-tier Skills (certified)
- 50+ marketplace page views
- 10+ community comments in GitHub discussions

---

## Phase 4 Kickoff (Week 9+)

After Phase 3e/3f stabilize:
- Announce Phase 4 (Vibe Engineering Hub)
- Multi-Agent orchestration
- Cross-Skill learning (Skills teaching each other)
