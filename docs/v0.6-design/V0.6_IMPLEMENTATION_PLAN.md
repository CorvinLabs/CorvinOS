**Owner:** Claude Code + team

---

## Executive Summary

v0.6 builds a **personalized operator model** (fingerprinting) that learns operator preferences and task strengths, enabling predictive guidance and counterfactual analysis. The system infers 4 dimensions (risk tolerance, speed, communication style, task affinities) from audit trail, then uses those to:

- Suggest next task (v0.6 Week 5-7)
- Guide decision-making by showing task affinity (v0.6 ongoing)
- Enable What-If replay for counterfactual exploration (v0.6 Week 5-7)

**Key invariant:** Fingerprinting starts on Day 1, but suggestions (output) are opt-in (default OFF), so v0.5 behavior is preserved during ramp-up.

**Test coverage:** 165+ tests (100 unit, 50 integration, 15 E2E)

```python
@dataclass(frozen=True)
class OperatorFingerprint:
    """Immutable operator style model."""
    
    operator_id: str
    tenant_id: str
    
    # Primary dimensions
    risk_tolerance: float            # [0.0..1.0]
    speed_preference: float
    communication_style: float
    
    # Task affinities
    task_affinities: Dict[str, TaskAffinity]
    
    # Metadata
    sample_count: int
    confidence: float
    last_updated: datetime
```

**Algorithm:**

```python
async def compute_fingerprint(
    operator_id: str,
    tenant_id: str,
    decision_window: int = 100,
) -> OperatorFingerprint:
    """
    Infer operator fingerprint from recent decision history.
    
    Args:
        decision_window: Number of recent decisions to consider
    
    Returns:
        OperatorFingerprint or None if <50 decisions collected
    """
    
    decisions = await load_recent_decisions(
        operator_id,
        tenant_id,
        limit=decision_window,
    )
    
    if len(decisions) < 50:
        return None  # not enough data
    
    # Compute dimensions
    risk_tolerance = compute_risk_tolerance(decisions)
    speed_preference = compute_speed_preference(decisions)
    communication_style = compute_communication_style(decisions)
    
    # Compute task affinities
    task_affinities = {}
    for task_type in TASK_TYPES:
        task_decisions = [d for d in decisions if d.task_type == task_type]
        if len(task_decisions) >= 5:
            task_affinities[task_type] = compute_task_affinity(task_decisions)
    
    return OperatorFingerprint(
        operator_id=operator_id,
        tenant_id=tenant_id,
        risk_tolerance=risk_tolerance,
        speed_preference=speed_preference,
        communication_style=communication_style,
        task_affinities=task_affinities,
        sample_count=len(decisions),
        confidence=min(1.0, len(decisions) / 30.0),
        last_updated=now(),
    )
```

#### 2.2 Task Affinity Model

**File:** `core/learning/affinity_model.py` (NEW)

```python
@dataclass(frozen=True)
class TaskAffinity:
    """Per-task-type success model."""
    
    task_type_id: str
    domain_boundary: str
    success_rate: float       # [0.0..1.0]
    sample_count: int
    confidence: float
    strength_tier: Literal["strong", "neutral", "weak"]
    last_practiced: datetime
    prior_strength: float  # difficulty prior


async def update_task_affinity(
    operator_id: str,
    tenant_id: str,
    task_type: str,
    outcome: Literal["success", "failure", "unclear"],
) -> TaskAffinity:
    """Bayesian update on turn outcome."""
    
    affinity = await load_affinity(operator_id, task_type)
    
    # Update counters
    if outcome == "success":
        success_count += 1
    elif outcome == "failure":
        failure_count += 1
    else:
        return affinity  # unclear, no update
    
    # Recalculate
    total = success_count + failure_count
    success_rate = success_count / total if total > 0 else 0.5
    confidence = min(1.0, total / 30.0)
    
    # Categorize
    if success_rate >= 0.75:
        strength_tier = "strong"
    elif success_rate >= 0.45:
        strength_tier = "neutral"
    else:
        strength_tier = "weak"
    
    updated = TaskAffinity(
        task_type_id=task_type,
        domain_boundary=TASK_TYPE_TO_DOMAIN[task_type],
        success_rate=success_rate,
        sample_count=total,
        confidence=confidence,
        strength_tier=strength_tier,
        last_practiced=now(),
        prior_strength=TASK_TYPE_DIFFICULTY_PRIOR[task_type],
    )
    
    await save_affinity(operator_id, task_type, updated)
    return updated
```

**Tests:** 15 unit + 8 integration

#### 3.1 ARIMA Task Predictor

**File:** `core/learning/task_predictor.py` (NEW)

```python
from statsmodels.tsa.arima.model import ARIMA

class TaskPredictor:
    """ARIMA(2, 1, 1) time-series model for task prediction."""
    
    async def predict_next_tasks(
        self,
        operator_id: str,
        tenant_id: str,
    ) -> List[TaskPrediction]:
        """Predict operator's next task(s)."""
        
        # Load recent task sequence (30 tasks)
        sequence = await load_task_sequence(
            operator_id, tenant_id, window=30
        )
        
        if len(sequence) < 5:
            return []  # not enough history
        
        # Encode task types as integers
        sequence_encoded = encode_sequence(sequence)
        
        # Fit ARIMA
        model = ARIMA(sequence_encoded, order=(2, 1, 1))
        model_fit = model.fit()
        
        # Predict next step
        forecast = model_fit.get_forecast(steps=1)
        pred_task_code = int(round(forecast.predicted_mean.values[0]))
        pred_task_type = TASK_CODES[pred_task_code]
        confidence = forecast.conf_int()[0][0]  # lower CI bound
        
        # Load operator's affinity for this task
        affinity = await load_affinity(operator_id, pred_task_type)
        
        return [
            TaskPrediction(
                task_type=pred_task_type,
                confidence=confidence,
                affinity_tier=affinity.strength_tier if affinity else "unknown",
            )
        ]
```

**Model tuning (Phase 4):** Based on real usage, adjust order to (p, d, q) with best AIC/BIC.

```python
@router.get("/api/learning/suggestions")
async def get_suggestions(request: Request) -> dict:
    """Return task suggestions for operator."""
    
    # Check feature flag
    if not is_feature_enabled(
        request.tenant_id,
        "operator_modeling_suggestions",
    ):
        return {"suggestions": [], "reason": "feature disabled"}
    
    # Predict next task
    predictor = TaskPredictor()
    predictions = await predictor.predict_next_tasks(
        request.operator_id,
        request.tenant_id,
    )
    
    # Filter by affinity and confidence
    suggestions = []
    for pred in predictions:
        if pred.confidence < 0.65:
            continue  # too uncertain
        
        if pred.affinity_tier == "weak":
            continue  # skip types operator struggles with
        
        suggestions.append({
            "task_type": pred.task_type,
            "confidence": pred.confidence,
            "affinity_tier": pred.affinity_tier,
            "reason": f"Based on your task history, {pred.task_type} is likely next.",
        })
    
    return {
        "suggestions": suggestions[:2],  # top 2 only
        "reason": "ARIMA model based on 30-task history",
    }
```

```python
@dataclass(frozen=True)
class DecisionSnapshot:
    """Immutable snapshot for counterfactual replay."""
    
    turn_id: str
    decision_point_id: str
    timestamp: datetime
    
    # Decision context
    available_options: List[Option]
    chosen_option: Option
    
    # Execution state (can restore for replay)
    context: Dict[str, Any]
    operator_fingerprint: OperatorFingerprint
    
    # Estimates
    estimated_cost: float
    estimated_quality: float
    
    # Metadata
    operator_id: str
    tenant_id: str
    created_at: datetime
    expires_at: datetime  # 30 days


async def replay(
    snapshot: DecisionSnapshot,
    counterfactual_option: Option,
) -> ReplayOutcome:
    """Execute turn with different option."""
    
    # Verify not expired
    assert now() < snapshot.expires_at
    
    # Restore context, substitute option
    context = snapshot.context.copy()
    context["chosen_option"] = counterfactual_option
    
    # Re-execute (deterministic, no randomness)
    outcome = await execute_turn_deterministic(context)
    
    # Compare
    return ReplayOutcome(
        actual=snapshot,
        counterfactual=outcome,
        cost_delta=outcome.cost - snapshot.estimated_cost,
        quality_delta=outcome.quality - snapshot.estimated_quality,
        trade_off=analyze_trade_offs(...),
    )
```

**Determinism guarantee:** Mock all external calls (APIs, databases, random). Use snapshotted values.

## Compliance Notes

**GDPR Art. 5 (Lawfulness):** Operator model inference based on lawful processing of operator's own decisions.

**GDPR Art. 6 (Legal Basis):** Fingerprinting = Art. 6(1)(b) contract fulfillment (necessary for personalization) + Art. 6(1)(a) consent (bot disclosure + Settings opt-out).

**GDPR Art. 30/32 (Records & Security):** Fingerprints stored locally, encrypted at rest, hash-chained in audit trail.

**GDPR Art. 17 (Right to Erasure):** Operator can request deletion → purges fingerprint + decision history, immediate effect.

**Data Minimization:** Collect only necessary data (decision choices, outcomes, annotations). Never collect prompts, responses, conversation history.
